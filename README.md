# Execução Longa — Formação LOOP-R Engenharia (curso 2 de 6)

Curso aberto e gratuito do INEMA.CLUB no formato INEMA Learning v7.2, em português, inglês e espanhol:
**https://inematds.github.io/loop-r-eng-execucao-longa-v72/** · [EN](https://inematds.github.io/loop-r-eng-execucao-longa-v72/en/) · [ES](https://inematds.github.io/loop-r-eng-execucao-longa-v72/es/)

Oito aulas para deixar um agente (Claude Code ou Codex) trabalhando por horas com o kit aberto [execucao-longa](https://github.com/inematds/execucao-longa): os sete arquivos de estado, o `goal.md` nível 3+, faixas de contexto, cache e ociosidade, handoff conferido, loop headless com `flock`/`timeout`/`MemoryMax`, medição de sessão e uma execução completa. Toda prática termina em "pronto quando: comando → saída esperada"; as saídas mostradas foram capturadas com o kit de 18/10/2026.

Conteúdo em `conteudo/<idioma>/` (JSON). O HTML é gerado: `python3 gerar.py && python3 validar.py --links` (e `--lang en|es`).
