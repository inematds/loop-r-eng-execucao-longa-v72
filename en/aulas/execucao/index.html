    04 · The cycle prompt and the close

    The prompt.md is what the loop sends to the agent in each cycle. Generalized from the pilot.

    longrun/[folder]/prompt.md (headless mode)
    You are in one cycle of a long run in the repo <project path>.

RESULT: <the goal.md result in one sentence>.

BEFORE ACTING: read goal.md → state.md → plan.md → the last lines of progress.md and failures.md (all in longrun/<folder>/).

IN THIS CYCLE: pick the next useful action, implement it, run <quick test>. If the quick ones pass, run <full test>.

AT THE END OF THE CYCLE (required):
- rewrite state.md (Funciona / Falta / Como retomar) and plan.md (next 3 steps);
- append 1 line to progress.md: date-time, what changed, test result (N passed / N failed);
- if something went wrong, 1 line in failures.md: error → attempt → result;
- design decisions in decisions.md.
- When the full test passes completely, write "concluído" on the first line of "## Funciona" in state.md.

CONSTRAINTS: do not change <protected files>. No API, no network. Do not commit (the outer loop does that).
    Terminal · close with independent verification
    cd ~/projetos/<seu-projeto>
head -5 longrun/<pasta>/state.md                       # says concluído?
<teste completo>                                        # run it yourself, don't read the log
git diff --exit-code <commit-base> -- tests/ pytest.ini; echo "protegidos: $?"
git diff --stat <commit-base>                           # only what the goal allowed?
grep -rn "<valor esperado de um teste>" <pasta do código>  # hardcoded value in the code?
python3 ~/projetos/execucao-longa/tools/medir-sessao.py <sessão.jsonl>

    05 · Final practice

    A real run of your own. Start small: 1 to 3 hours.

    E19 · One run from start to finish

    1–3 h

    In the folder from lessons 1 and 2, freeze the tests, pick the mode (/goal or loop-longrun.sh rehearsed with a fake agent) and let it run with the hook and the vigia on. Step in only for the stop rules.

    Done when: the first line of "## Funciona" in state.md says concluído and the loop.log (in headless) ends in CONCLUÍDO no ciclo N, or the run stopped on one of the kit's rules with the reason in failures.md.

    E20 · Close and measure

    30 min

    Close with the independent verification block and measure the session. Write the final line in progress.md and, if there was a failure, the smallest fix in the project's FALHAS.md.

    Done when: the full test, run by you, passes; git diff --exit-code [base-commit] -- tests/ → protegidos: 0; progress.md has the final line with tokens and compactions from medir-sessao.py.
