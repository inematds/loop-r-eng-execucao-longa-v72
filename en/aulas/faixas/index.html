Lesson 3 · 18 min

Context in bands: 50, 70 and 85% of the compaction point

The biggest enemy of a long session is repeated compaction: the goal survives, but what is done and what remains get diluted. The hook-longrun measures the context and acts before the limit, in three bands. In this lesson you turn on the hook and trigger all three bands in a rehearsal, without spending a token.

Start the lesson

In this lesson you will

  1. 1Where the bands sit: ~484, ~677 and ~822 thousand tokens
  2. 2Compaction × handoff: what each one keeps
  3. 3Turn on the hook for the five Claude Code events
  4. 4Rehearse the hook with a fake transcript

Goal: turn on the hook-longrun and trigger the three bands in a rehearsal, knowing what each one asks of the agent and when to do /clear + /prime.

01 · The bands over the compaction point

The percentage is of the point at which Claude Code compacts by size, not of the whole window.

In the measurements from 10/07 to 10/15/2026, no session compacted by size: all 93 compactions were due to idle time (lesson 4).

Hook-longrun 1.9.6 (10/18/2026). The bands change with LONGRUN_FAIXAS="50,70,85". The warning arrives one tool call later, because the transcript is written with a delay.

02 · Compact, write a handoff, or open a new session

What each path keeps, measured on 10/15/2026 (17 compactions with a handoff from the same session in the 3 h before).

1. Compaction

The summary cites 20 to 54 files and keeps recent steps and commands. Within the same session, it holds more concrete detail than the handoff.

But it doesn't separate what's confirmed from what's a guess, it mixes the decisions into the narrative, and it doesn't survive /clear.

2. Handoff

It cites 1 to 27 files, but it marks what was proven, and keeps the decisions and the next action in a section of their own.

It's the only one that works for another session, another day, or Codex. The two together are better than either one alone.

Mistake to avoidWriting the handoff from the compaction summary: it becomes a copy of a copy.

3. /clear + /prime

The new session rediscovers things: 80% of the first 25 steps were reads, versus 51–59% after compacting.

That's why the new session comes at band 3 or the 3rd compaction, at the end of the unit in progress, and not early.

4. Spend less context

Half of a 1.84 GB JSONL measured on 10/01/2026 was tool output. Write logs to a file and read the part you need (tail -50).

A subagent spends its own context and returns only the summary; Anthropic cites returns of 1,000 to 2,000 tokens. How to use subagents is the topic of course 3.

03 · Turn on the hook and rehearse the bands

The rehearsal writes a fake transcript with whatever number of tokens you want and calls the hook the way Claude Code would.

ensaio-hook.sh · save to a file and run with bash
# ensaio-hook.sh — dispara o hook-longrun com uma transcrição FALSA (nenhum token gasto)
# uso: bash ensaio-hook.sh <tokens|-> [minutos-parado] [evento]     ("-" reaproveita a transcrição anterior)
E=/tmp/ensaio-hook; K=~/projetos/execucao-longa
mkdir -p $E/proj/longrun/2026-10-19-teste $E/proj/handoffs/history
[ -f $E/proj/longrun/2026-10-19-teste/state.md ] || echo "# Estado" > $E/proj/longrun/2026-10-19-teste/state.md
[ "${1:-500000}" = "-" ] || python3 - "${1:-500000}" "${2:-0}" > $E/t.jsonl <<'PY'
import json, sys, time, datetime
n, parado = int(sys.argv[1]), float(sys.argv[2])
ts = datetime.datetime.fromtimestamp(time.time() - parado * 60, datetime.timezone.utc).isoformat().replace("+00:00", "Z")
print(json.dumps({"type": "assistant", "timestamp": ts, "message": {"model": "claude-opus-5-5",
      "content": [{"type": "text", "text": "ok"}],
      "usage": {"input_tokens": 10, "cache_read_input_tokens": n - 10, "cache_creation_input_tokens": 0}}}))
PY
echo "{\"hook_event_name\":\"${3:-PostToolUse}\",\"cwd\":\"$E/proj\",\"session_id\":\"ensaio\",\"transcript_path\":\"$E/t.jsonl\",\"prompt\":\"oi\"}" \
  | LONGRUN_ESTADO=$E/estado LONGRUN_AGENDAR_ARQ=$E/agenda.jsonl python3 $K/tools/hook-longrun.py
echo

  • There is no compaction hook or counter. Track the percentage in /status; what follows the bands is the AGENTS.md rule (lesson 1) and you.
  • Measured in the kit: Codex compacts near 90–93% of the window, around 230–240 thousand of 258 thousand, too late for good summary quality. Do the manual /compact earlier.
  • With an OpenAI model, automatic compaction runs on the server and ignores the compact_prompt; the structured prompt in ~/.codex/config.toml only applies to the manual /compact.
