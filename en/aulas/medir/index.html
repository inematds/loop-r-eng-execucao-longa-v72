Lesson 7 · 17 min

Measure the session: medir-sessao.py, resume cost, and recall

Without measuring, "the session got expensive" and "the agent forgot" are just impressions. The kit reads the JSONL transcripts from Claude Code and Codex and gives you duration, compactions, tokens and cache per turn, the real cost of resuming, and a search across everything that has been said. In this lesson you measure a known case and then your biggest session.

Start the lesson

In this lesson you will

  1. 1Where the Claude and Codex transcripts live
  2. 2medir-sessao.py: summary, --json and --por-turno
  3. 3custo-retomada.py and nota-retomada.py
  4. 4recall: search in 0.02 s through everything that has been said

Goal: measure the duration, compactions, tokens and cache of a session, read the cost of resuming, and find an old decision with recall.

03 · How to read it and where to note it

One line per run in progress.md, with the tool's numbers.

1. Cache

Between 93% and 99% is the normal measured in long sessions. Much lower than that in a long session, look for pauses longer than the cache or a model switch midway.

Compaction does not drop the cache: it is no reason to cut the session short.

2. Compactions

In Claude, compact_boundary lines; in Codex, compacted lines. Three in the same session: the hook has already asked for a new session at the end of the task (lesson 3).

To see when, use --json --por-turno and look for where the compactacoes column goes up.

3. Tool output

It is not a limit: the big file does not block anything; what weighs is the context. But if it dominates, the agent is reading a whole log instead of tail -50.

4. progress.md

On the final checkpoint line: input tokens / cache read / output and compactions, as the pilot did.

It is what lets you compare the next run with this one.

Pilot line (10/01/2026)| 2026-10-01 14:30 | medição do piloto | 7714c3c | sim (nível 3) | 332791 / 304000 / 4296 (cache 91,3%) | 0 |

04 · Practice

First the known case, then your own data.

E16 · The tool matches on your machine

5 min

Measure both fixtures and run the recall rehearsal.

Done when: claude_mini → compactações: 1 | turnos: 2 and cache: 45.0%; codex_mini → cache: 60.0%; recall prints 2 arquivos processados; 8 trechos novos., then 0 arquivos processados and a line with PostgreSQL.

E17 · Your biggest session in progress.md

15 min

Measure the biggest transcript from your Claude Code (or one from Codex in ~/.codex/sessions) and write the line in the progress.md of your run, with the date.

Done when: the progress.md line has input tokens, cache read, output, and compactions equal to those medir-sessao.py printed for the same file.

E18 · Recall on your sessions

15 min

Install the recall command, index, and look for a decision you remember making with the agent in the last week.

Done when: recall indexar → N arquivos processados with N greater than 0, and recall "[term]" --desde [date] returns the line with the file and the conversation line number.
